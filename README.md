# trabalhoPOO
Labirinto de Mistérios
Labirinto de Mistérios é um jogo em Java com interface gráfica, onde o jogador deve explorar um labirinto gerado aleatoriamente, coletar tesouros e evitar armadilhas escondidas. O projeto foi desenvolvido com base nos conceitos de orientação a objetos e interface com Swing.

Funcionalidades
Movimento com as teclas W, A, S, D

Coleta de tesouros (representados em amarelo)

Sistema de skins para o personagem

Labirinto com paredes invisíveis e perigos indicados discretamente

Poder especial para destruir até 2 paredes por partida com a tecla P

Ranking de pontuação com nome e score do jogador

Controles
Tecla	Função
W	Mover para cima
A	Mover para a esquerda
S	Mover para baixo
D	Mover para a direita
P	Usar poder (destruir parede)
